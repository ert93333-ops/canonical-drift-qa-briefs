FAQ

Canonical constraints are explicit.

Does it crawl my site?

No. This MVP only analyzes pasted URL, canonical, sitemap, and redirect notes.

Does it use Search Console?

No. There is no Search Console, URL Inspection, OAuth, or external API dependency.

Does it guarantee Google's selected canonical?

No. Search engines choose canonicals from multiple signals. This is launch QA guidance, not an outcome guarantee.

Can I paste private client URLs?

The app is browser-local, but you should still paste only public-safe or anonymized rows.
