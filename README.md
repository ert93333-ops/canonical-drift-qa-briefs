# Canonical Drift QA Briefs

Static MVP for checking pasted URL, canonical, sitemap, and redirect rows before migrations or launch pages go live.

## Offer

Paste page URL/canonical rows, optional sitemap rows, launch context, redirect notes, and canonical owner. Generate a copyable QA brief covering:

- missing canonical warnings
- page URL vs canonical mismatch
- HTTP/HTTPS and trailing slash drift
- staging, preview, dev, test, draft, or localhost URLs
- cross-domain canonical risk notes
- sitemap/canonical disagreement
- redirect and final URL reminders

## Conversion Path

Billing is not connected. The MVP uses early-access, demo-request, and purchase-intent capture with a public-safe GitHub issue handoff.
